GramSoul

Ролевые чаты с ИИ-персонажами вместе с друзьями.

Открыть в браузере Скачать для Android
Компьютер
Просто открой в любом браузере: слева меню, рядом с чатом — список переписок, Enter отправляет сообщение.

iPhone
Открой эту страницу в Safari, нажми «Открыть в браузере», затем «Поделиться» ⬆︎ → «На экран „Домой“». GramSoul появится иконкой и будет открываться на весь экран, как приложение.

Android
Скачай GramSoul.apk, открой файл и разреши установку из этого источника. Обновления ставятся поверх.

Аккаунт один: войти с другого устройства можно по коду переноса из профиля.
